MULA MENERBITKAN
1. Ekstrak ZIP dan buka folder joran-minda.
2. Gunakan repositori GitHub yang disambungkan kepada laman Netlify asal.
3. Letakkan kandungan folder joran-minda pada aras projek sedia ada.
   package.json, netlify.toml, public, scripts, server dan netlify mesti
   berada pada aras yang sama. Kekalkan susunan subfolder di dalamnya.
4. Muat naik keseluruhan projek. GitHub Desktop sesuai untuk memindahkan
   semua fail dalam satu kemas kini. Muat naik melalui laman GitHub
   dihadkan kepada 100 fail setiap kali dan 25 MiB setiap fail.
5. Simpan perubahan (commit) dan hantar ke GitHub (push).
6. Jika penerbitan automatik sudah disambungkan, tunggu penerbitan Netlify
   selesai. Semak log jika penerbitan gagal.
7. Buka laman Netlify, kemudian Ruang Guru > Semak sambungan bilik.
   Sambungan perlu menyatakan versi 34. Cipta bilik baharu untuk soalan baharu.

TETAPAN PROJEK
Fail netlify.toml menyediakan arahan binaan, folder public dan fungsi
netlify/functions serta Node 22. Kekalkan fail itu bersama package.json.
Jika projek berada dalam subfolder repositori, tetapan direktori asas
Netlify perlu menunjuk kepada subfolder yang mengandungi kedua-dua fail itu.
Fail ZIP perlu diekstrak; fail pratonton HTML ialah untuk mencuba pada
satu peranti dan tidak menyediakan perkhidmatan kod bilik dalam talian.

SEMAKAN SELEPAS TERBIT

Semak audio, giliran ahli, rakaman murid, rekod Guru dan sijil.
